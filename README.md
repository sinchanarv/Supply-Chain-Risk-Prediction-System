# SupplyGuard: AI-Powered Supply Chain Risk Prediction

## 🚀 Project Overview
This is a Proactive Global Supply Chain Vulnerability Mapping system. It uses AI/NLP to read global unstructured news data and predicts logistics failures before they happen using an interactive digital twin map.


### 
1. Clone the Repository
Open your terminal and run:

git clone https://github.com/sinchanarv/Supply-Chain-Risk-Prediction-System.git

2. Switch to the Frontend Branch
The completed UI code is sitting on the frontend branch.
git checkout frontend

3. Install React Dependencies
You need Node.js installed on your computer. Navigate into the frontend folder and install the required packages (Tailwind, Lucide Icons, Leaflet Maps):

cd frontend

npm install

4. Run the Development Server

npm run dev

Click the http://localhost:5173 link in the terminal.

You will see the Dashboard!
